# 019 — PWA: installable, offline shell

**Blocked by:** 014 · **Blocks:** 020

## Goal

The app installs to the phone's home screen, opens like a native app, and **opens instantly with no signal**.

This is what the user actually asked for when they said *"save the app as a shortcut on the home screen"*. Without it, the offline session player from 011–014 is undermined by the app shell itself failing to load in the gym.

## Scope

- `manifest.json` — name, icons (192/512 + maskable), `display: 'standalone'`, theme colour, `start_url: '/'`.
- Icons, and the iOS meta tags (`apple-mobile-web-app-capable`, `apple-touch-icon`) — iOS still doesn't fully read the manifest.
- A **service worker** caching the app shell so `/` and `/session` load with no network.
- `navigator.storage.persist()` — request persistent storage **once the app is installed**. Without it, the browser may evict IndexedDB under storage pressure, which would take a live session draft with it ([ADR-0001](../../../docs/adr/0001-offline-first-session-player.md) names this as the one real risk of the design). This single line is the mitigation.
- An install prompt (`beforeinstallprompt`), shown non-annoyingly — once, dismissible, never again.

## The trap

**Do not let the service worker cache API responses or Supabase auth requests.** Cache the *shell* — HTML, JS, CSS, icons. A stale-cached auth token or a stale program list is a genuinely nasty class of bug: the user edits their program, reloads, and sees the old one, with no way to understand why. Network-first (or network-only) for anything from Supabase; cache-first only for static assets.

## Acceptance

- Installable on Android (Chrome) **and** iOS (Safari → Add to Home Screen). Test both — iOS is the one that will be broken.
- Launched from the home screen, it opens standalone (no browser chrome).
- **Airplane mode, cold launch from the home screen → the app opens** and a session draft is intact and resumable.
- Editing a program and reloading shows the edit (i.e. you did not cache the data layer).
